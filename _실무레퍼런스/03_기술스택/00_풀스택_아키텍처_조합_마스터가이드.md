# 웹, 데스크톱(.exe), 모바일(.apk), 크롬 확장앱, DB, 도커, 결제 풀스택 조합 마스터 가이드 (모듈형 조립 설계도)

- **기준일**: 2026-10-25
- **적용 대상**: 프로젝트를 시작할 때 프론트엔드, 백엔드, 데스크톱 포터블 패키징, 데이터베이스, 도커/인프라, 결제/라이선스를 따로따로 찾아 헤매지 않고, **"내가 만들 프로그램에 어떤 부품을 붙이고 어떤 부품을 뺄지(있음/없음)"** 한 페이지에서 결정하고 조립하는 마스터 설계도입니다.
- **정렬 원칙**: 모든 모듈과 레시피는 **현재 실무에서 가장 많이 사용하는 주력 기술부터 우선 배치**하고, 특수 목적이나 저빈도 조합은 뒤쪽에 배치했습니다.

## 1. [6단계 조립식 모듈] 프로젝트에 필요한 부품 선택하기 (실사용 빈도순 배치)

모든 프로그램이 무거운 백엔드나 DB, 도커, 결제를 다 갖춰야 하는 것은 아닙니다. 아래 6가지 모듈 중 내 프로젝트에 필요한 번호만 골라 조립합니다.

### 모듈 A. 화면(UI) 및 클라이언트 껍데기 선택 (실사용 빈도순)
1. **모던 웹 SPA 표준 (`React 19 + Vite 6 + TypeScript + Tailwind CSS v4 + shadcn/ui`)**: 상용 웹서비스, SaaS, 실시간 대시보드, 그리고 향후 `.exe` / `.apk` / 크롬 확장앱으로 원소스 멀티유즈 변환까지 모두 커버하는 1순위 표준입니다.
2. **크롬 확장프로그램 (`WXT + React 19 + Tailwind CSS + Offscreen Document`)**: 브라우저 툴바 팝업, 사이드패널, 웹페이지 오버레이(`Shadow DOM`), 캡처/녹화/PDF/온디바이스 AI 확장앱 표준입니다.
3. **프론트엔드 빌드 없는 초고속 웹 (`FastAPI + Jinja2 + HTMX 2.0 + Tailwind CSS v4`)**: Node.js 설치나 별도 빌드 없이 파이썬 백엔드 폴더 하나로 사내 관리툴과 어드민 화면을 가장 빠르게 띄울 때 선택합니다.
4. **윈도우 데스크톱 (`.exe`)**:
   - **올인원/상용급**: `Electron + React` (또는 10MB 초경량 `Tauri 2.0 + React`)
   - **가벼운 포터블/단일 실행파일**: `Pywebview (HTML/Tailwind)` 또는 `PySide6 (Qt 위젯)`
5. **안드로이드 모바일 (`.apk`)**: `Capacitor` (React/Vue 웹 소스를 실제 `.apk`로 패키징) 또는 `PWA` (빌드 0일, 모바일 크롬 홈화면 설치)
6. **파이썬 100% 웹 UI (`Streamlit` / `NiceGUI`)**: HTML/JS 코딩을 아예 생략하고 파이썬 코드만으로 데이터 분석 리포트나 장비 제어용 화면을 만들 때 선택합니다.

### 모듈 B. 백엔드 서버 선택 (원격 서버 vs 포터블 내장 vs 백엔드 없음)
1. **중앙 집중형 원격 백엔드 서버 (`Python FastAPI + Uvicorn`)**: 다수의 사용자와 클라이언트가 동시 접속하는 표준 웹/API/WebSocket 서버입니다. (대규모 실시간 소켓 통신 시 `Python asyncio` TCP 서버 결합)
2. **백엔드 없음 (순수 클라이언트 무서버형)**: 크롬 확장앱, 단독 실행 포터블 `.exe` 유틸리티, 정적 웹툴. 서버 유지비 0원이며 장애 포인트가 없습니다.
3. **포터블 내장형 백엔드 (`Sidecar .exe`)**: 사용자가 데스크톱 앱(`Setup.exe`)을 실행하면 내부에서 `app_engine.exe`(Python `FastAPI` 단일 빌드 파일)가 검은 콘솔 창 없이 조용히 켜지고 앱 종료 시 함께 꺼지는 구조입니다. 별도 서버 PC가 필요 없습니다.

### 모듈 C. 데이터베이스(DB) 선택 (실사용 빈도순)
1. **설치 없는 단일 파일 DB (`SQLite WAL 모드`)**: 포터블 `.exe` 프로그램, 중소규모 웹서버, 사내 툴에 파일(`app.db`) 하나로 내장합니다. 별도 DB 서버 설치가 전혀 필요 없습니다.
2. **엔터프라이즈 표준 서버 DB + 캐시 (`PostgreSQL 16+` & `Redis 7+`)**: 상용 웹서비스, SaaS, 대용량 로그 파티셔닝, 실시간 상태 캐시 및 메시지 큐가 필요한 중대형 시스템의 부동의 1위 조합입니다.
3. **브라우저/클라이언트 내장 대용량 DB (`IndexedDB` + `Dexie.js`)**: 크롬 확장프로그램이나 모바일 웹앱 내부에 고해상도 이미지, 영상, PDF Blob을 저장할 때 사용합니다.
4. **대용량 파일 분석 전용 DB (`DuckDB`)**: DB 서버 없이 수십 개의 대용량 `.xlsx`, `.csv`, `.parquet` 파일을 직접 읽어 SQL 통계 집계를 초고속으로 뽑아낼 때 사용합니다.
5. **DB 없음 (파일/메모리 직접 처리)**: 엑셀(`.xlsx`), CSV, 바이너리 파일을 읽어서 바로 가공 후 파일로 저장하는 단발성 유틸리티.

### 모듈 D. 배포 및 실행 인프라 선택 (실사용 빈도순)
1. **Docker Compose 컨테이너 통합 배포 (`docker-compose.yml`)**: `FastAPI + PostgreSQL + Redis + Caddy(무료 HTTPS)`를 파일 하나로 묶어 개발 PC와 운영 서버를 100% 동일하게 원클릭 기동합니다. (폐쇄망은 `.tar` 이미지로 오프라인 이관)
2. **무설치 포터블 단일 `.exe` (`PyInstaller -F -w` / `Nuitka`)**: 파이썬이 없는 다른 윈도우 PC에 `.exe` 파일 1개만 복사해 주면 더블클릭으로 즉시 실행됩니다.
3. **도커 없는 윈도우/리눅스 백그라운드 서비스 (`WinSW` / `systemd`)**: 도커 설치가 부담스러운 단일 윈도우 서버나 현장 PC에서 `service.exe`로 등록하여 재부팅 시 자동 실행 및 오류 종료 시 5초 만에 자동 재시작합니다.

### 모듈 E. 외부 접속 및 네트워크 연결 선택
1. **무료 자동 HTTPS 리버스 프록시 (`Caddy` 또는 `Nginx`)**: 도메인 연결, SSL 인증서 자동 갱신, 대용량 정적 파일 직접 서빙을 처리합니다.
2. **포트포워딩 없는 외부 도메인 공개 (`Cloudflare Tunnel`)**: 공유기 포트포워딩이나 고정 IP 없이도 로컬 서버를 `https://내도메인.com`으로 외부 고객 및 결제 웹훅에 안전하게 공개합니다.
3. **포트포워딩 없는 나/팀원 전용 사설망 (`Tailscale`)**: 외부 인터넷에 포트를 전혀 열지 않고 내 집 PC, 스마트폰, 사무실 서버만 고정 사설 IP(`100.x.y.z`)로 1분 만에 직결합니다.

### 모듈 F. 결제 및 라이선스 수익화 선택 (실사용 빈도순)
1. **무서버 시리얼 라이선스 키 검증 (`Lemon Squeezy` / `Polar.sh`)**: 자체 결제 백엔드나 회원 DB 서버 없이, 크롬 확장앱이나 포터블 `.exe` 프로그램에서 시리얼 키(`XXXX-YYYY-...`) 입력만으로 정품 인증, 기기 대수 제한, 해외 세금(MoR) 처리를 끝냅니다.
2. **국내 웹/SaaS 카드 및 간편결제 (`토스페이먼츠 v2` / `포트원 V2`)**: 국내 사용자 대상 신용카드, 카카오페이, 네이버페이, 월 정기구독(빌링키) 및 휴대폰 본인인증(다날)을 `FastAPI + PostgreSQL`과 연동합니다.
3. **모바일 스토어 인앱결제 (`Google Play Billing + RevenueCat`)**: 구글 플레이스토어 정식 출시 `.apk` 앱 내부에서 정기구독 상품을 판매할 때 사용합니다.
4. **폐쇄망 오프라인 하드웨어 UUID 잠금**: 인터넷이 안 되는 기관/기업 PC에 `.exe` 납품 시 메인보드 고유 UUID 기반 시리얼 키로 타 PC 무단 복사를 차단합니다.

## 2. 실무에서 가장 많이 쓰는 [완성형 풀스택 아키텍처 레시피 12선] (실사용 빈도순)

현재 가장 활용 빈도가 높은 핵심 조합을 1번부터 앞쪽에 배치했습니다.

### 레시피 01. [크롬 확장앱 MV3 + 무서버 + 로컬 IndexedDB + 시리얼 키 결제] 1인 개발 및 수익화 1순위
내가 24시간 관리해야 하는 백엔드 서버나 DB 서버가 아예 없어서 **유지비 0원, 서버 장애 걱정 0%**이면서 전 세계 사용자에게 유료로 배포·판매할 수 있는 최고 효율의 조합입니다.
- **화면(UI)**: `WXT + React 19 + Tailwind CSS v4` (Popup, SidePanel, Content Script `Shadow DOM` 격리)
- **백엔드**: 없음 (브라우저 내 `Background Service Worker` + `Offscreen Document`가 모든 처리 담당)
- **로컬 스토리지(DB)**:
  - 가벼운 설정/라이선스 상태: `chrome.storage.local` + `Zod` 스키마 검증
  - 고해상도 캡처 이미지/녹화 영상/PDF 대용량 Blob (64MiB 메시지 한도 우회): `IndexedDB (Dexie.js)`
- **미디어/문서/온디바이스 AI 엔진**: `Canvas API` + `MediaRecorder` + `pdf-lib` + `ONNX Runtime Web / Tesseract WASM` (서버 API 비용 0원)
- **결제/라이선스**: `Lemon Squeezy` 또는 `Polar.sh` 라이선스 키 검증 API (7일 주기 백그라운드 자동 재검증)
- **짝꿍 스킬 및 MCP**: `[스킬] wxt, chrome-mv3, chrome-extensions, indexeddb-storage, web-audio-video, pdf-lib, ai-wasm, i18n-localization` + `[MCP] Context7, Playwright, Lemon Squeezy MCP`

### 레시피 02. [웹 SPA + 백엔드 분리 + 서버DB + 도커] 모던 상용 웹서비스 및 대시보드 표준
복잡한 인터랙션, 대용량 데이터 그리드, 실시간 차트/웹소켓이 필요한 상용 웹서비스 및 통합 대시보드 구축 시 가장 널리 쓰이는 정석 조합입니다.
- **화면(UI)**: `React 19 (Vite 6) + TypeScript + Tailwind CSS v4 + shadcn/ui + TanStack Query/Table`
- **백엔드**: `Python FastAPI (REST API & WebSocket)`
- **데이터베이스**: `PostgreSQL 16` (메인 RDBMS) + `Redis 7` (실시간 캐시 및 작업 큐)
- **배포/인프라**: `Docker Compose` + `Caddy` (또는 `Nginx` 정적 파일 서빙 및 리버스 프록시)
- **결제/외부접속**: 필요 시 `토스페이먼츠 v2` 연동 + `Cloudflare Tunnel` 외부 도메인 연결
- **짝꿍 스킬 및 MCP**: `[스킬] fastapi-templates, vercel-react-best-practices, tailwind-design-system, postgresql, docker-compose-orchestration` + `[MCP] Context7, Playwright, PostgreSQL MCP, Redis MCP, Docker MCP`

### 레시피 03. [웹 + 백엔드 통합 + 로컬DB + 무도커] 초고속 사내 관리 웹 및 어드민 툴
Node.js/React 빌드 과정도 필요 없고, 도커나 무거운 DB 서버 설치도 필요 없이 파이썬 폴더 하나로 즉시 띄우는 사내 시스템 가성비 1위 조합입니다.
- **화면(UI)**: `Jinja2 + HTMX 2.0 + Alpine.js + Tailwind CSS v4` (프론트엔드 빌드 불필요)
- **백엔드**: `Python FastAPI`
- **데이터베이스**: `SQLite (WAL 모드)` 단일 파일 (`app_local.db`)
- **배포/인프라**: `uv run` + 윈도우 서비스 `WinSW` (도커 불필요, 부팅 시 백그라운드 자동 실행)
- **결제/외부접속**: 결제 없음(사내용) + 외부 접속 필요 시 `Tailscale`
- **짝꿍 스킬 및 MCP**: `[스킬] fastapi-templates, htmx-jinja-templates, tailwind-design-system, sqlite-embedded-db` + `[MCP] Context7, Playwright, SQLite MCP`

### 레시피 04. [웹 SPA + 백엔드 + 서버DB + 국내결제 + 도커] 국내 상용 유료 SaaS 플랫폼
일반 고객이나 기업 회원을 대상으로 회원가입, 본인인증, 신용카드/간편결제 정기구독을 제공하는 수익형 웹서비스 풀스택 조합입니다.
- **화면(UI)**: `React 19 (또는 Next.js 15) + Tailwind CSS v4 + shadcn/ui + 토스페이먼츠 결제위젯 v2`
- **백엔드**: `FastAPI` (JWT/OAuth 인증, `/api/payments/confirm` 결제 금액 위변조 검증, 결제 웹훅 수신)
- **데이터베이스**: `PostgreSQL 16 + SQLAlchemy 2.0 Async + Alembic`
- **배포/인프라**: `Docker Compose + Caddy (3줄 설정 무료 HTTPS 자동 갱신)`
- **결제/수익화**: `토스페이먼츠 v2` (단일 PG) 또는 `포트원 V2` (복수 PG + 다날 휴대폰 본인인증)
- **짝꿍 스킬 및 MCP**: `[스킬] fastapi-templates, vercel-react-best-practices, postgresql` + `[MCP] Toss Payments MCP (또는 PortOne MCP), PostgreSQL MCP, Playwright`

### 레시피 05. [데스크톱 Electron/Tauri .exe + 포터블 파이썬 Sidecar + 로컬DB + 라이선스] 올인원 데스크톱 소프트웨어
화려한 React 화면과 파이썬의 무거운 연산(AI 비전, 대용량 엑셀/PDF 조판, 로컬 자동화)을 하나의 설치 파일(`Setup.exe`)로 묶어 배포·판매하는 데스크톱 표준 조합입니다.
- **화면(UI)**: `Electron` (또는 10MB 초경량 `Tauri 2.0`) + `React 19 + Tailwind CSS v4 + shadcn/ui`
- **포터블 내장 백엔드 (Sidecar)**: 파이썬으로 빌드한 `app_engine.exe`(`FastAPI`)를 Electron 메인 프로세스가 콘솔 창 없이(`windowsHide: true`) 실행하고 앱 종료 시 `taskkill /pid <PID> /t /f`로 깔끔히 회수
- **데이터베이스**: 내장 `SQLite (WAL 모드)` + `DuckDB` (로컬 대용량 파일 분석 시)
- **결제/라이선스**: 온라인 판매 시 `Lemon Squeezy / Polar.sh` 시리얼 키 API, 오프라인 납품 시 `메인보드 UUID 서명 키` 검증
- **짝꿍 스킬 및 MCP**: `[스킬] electron-architecture, electron-python-sidecar, vercel-react-best-practices, sqlite-embedded-db` + `[MCP] Context7, SQLite MCP, Lemon Squeezy MCP`

### 레시피 06. [데스크톱 포터블 단일 .exe + 노서버 + 로컬파일/SQLite] 초경량 무설치 유틸리티
