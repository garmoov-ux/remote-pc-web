# 기술 스택 조합 통합 100선 (실무 아키텍처 표준 레퍼런스)

- **산정 기준**: 실제 현업 사용 빈도, 생산성, 유지보수 안정성, 런타임 성능, AI 코딩 에이전트 친화도 종합 평가 (실사용 빈도가 높은 주류 조합을 최상단에 배치)
- **작성 일자**: 2026년 10월 25일
- **적용 대상**: 크롬 확장 프로그램(MV3), 상용 웹서비스 및 SaaS, 데스크톱 실행파일(.exe), 모바일 앱(.apk), 사내 관리 시스템, 오피스 자동화, 실시간 데이터 수집 서버

## 1. 타깃 플랫폼별 10초 선택 기준 (실사용 빈도순)

- **크롬 확장 프로그램 (Chrome Extension Manifest V3) [1순위 주력]**
  - 자동 매니페스트 생성과 HMR을 지원하는 `WXT + React 19 + Tailwind v4 + Chrome Manifest V3`를 기본으로 하며, 대용량 미디어·PDF 처리는 `Offscreen Document + IndexedDB (Dexie.js)`를 결합합니다.
- **상용 웹 서비스 및 통합 대시보드 (중대형 / 다수 사용자) [2순위 주력]**
  - 대량 데이터 그리드, 실시간 차트, 복잡한 상태 관리가 필수이므로 `FastAPI + React 19 (Vite) + Tailwind v4 + shadcn/ui` 조합을 표준으로 채택합니다.
- **사내 관리 웹 및 어드민 시스템 (소규모 / 빠른 구축)**
  - 프론트엔드와 백엔드를 분리하지 않고 파이썬 단일 언어로 화면과 API를 즉시 구축하는 `FastAPI + Jinja2 + HTMX 2.0 + TailwindCSS` 조합을 선택합니다.
- **결제 및 라이선스 수익화 (SaaS / 패키지 판매)**
  - 별도 백엔드 서버 없이 크롬 확장앱이나 `.exe` 프로그램을 유료 판매할 때는 `Lemon Squeezy / Polar.sh (무서버 라이선스 키 검증 API)`를 결합하고, 국내 웹 서비스 정기·단건 결제는 `FastAPI + 토스페이먼츠 v2 + PostgreSQL`을 사용합니다.
- **윈도우 데스크톱 프로그램 (.exe 독립 실행파일)**
  - 고성능 로컬 DB와 파이썬 연산이 필요하면 `Electron + React + 내장 Python FastAPI (.exe Sidecar) + SQLite WAL`을 선택하고, 10MB 미만의 초경량 설치 용량이 중요하면 `Tauri 2.0 + React` 또는 무설치 포터블 `Pywebview / PySide6 + PyInstaller`를 선택합니다.
- **안드로이드 모바일 앱 (.apk 하이브리드 앱)**
  - 기존 웹 프론트엔드 코드를 그대로 재활용하여 카메라, GPS, 파일시스템 등 네이티브 기능을 제어할 수 있는 `React/Vue + TailwindCSS + Capacitor (.apk)` 조합을 선택합니다.
- **엑셀 및 오피스 문서 자동화 (현업 부서 배포)**
  - 현업 담당자에게 익숙한 엑셀 화면에 버튼을 두고 무거운 데이터 처리는 백그라운드 실행파일이 수행하는 `Excel VBA (시트 버튼) + Python CLI (.exe) + openpyxl` 조합을 선택합니다.
