- **산정 기간**: 2026년 8월 ~ 2026년 10월 (최근 3개월)
- **산정 지표**: 신규 프로젝트 채택 증가율, AI 에이전트(바이브 코딩) 호환성, 빌드·실행 속도 혁신성, 운영 비용 절감 효과
- **작성 일자**: 2026년 10월 25일

## 1. 최근 3개월 기술 스택 조합의 3대 핵심 변화

- **1. 무거운 레거시 설정 도구의 완전 퇴출 (Zero-Config & Rust 기반 툴체인)**
  - 파이썬 생태계에서는 느리고 충돌이 잦던 `pip + venv + poetry + black + flake8` 조합이 사라지고 **`uv + Ruff`** 단일 워크플로우로 완전히 재편되었습니다.
  - 프론트엔드 생태계에서는 복잡한 설정 파일이 필요하던 `ESLint + Prettier`가 **`Biome`**으로 대체되었고, `tailwind.config.js`가 불필요한 **`Tailwind CSS v4 (@tailwindcss/vite)`**가 기본 표준으로 자리 잡았습니다.
- **2. 서버 유지비 0원(Zero-Server Cost) 아키텍처의 폭발적 확산**
  - 크롬 확장 프로그램과 데스크톱 앱에서 클라우드 AI API 호출 비용을 없애기 위해 **`ONNX Runtime Web (WebGPU) + Transformers.js v3 + Tesseract WASM`**을 활용한 브라우저 내 온디바이스 AI 조합이 급격히 증가했습니다.
  - 대용량 데이터 저장은 **`IndexedDB (Dexie.js)`** 및 **`SQLite WAL / OPFS`**로 로컬화하고, 수익화는 자체 서버 없이 **`Lemon Squeezy / Polar.sh 라이선스 키 API`**로 해결하는 1인·소규모 고수익 구조가 대세입니다.
- **3. 문서·바이너리 AI 파이프라인과 역공학(REA) 재구현 스택의 결합**
  - 단순 챗봇을 넘어 사내의 복잡한 표·수식이 포함된 PDF/오피스 문서를 **`Docling + MarkItDown`**으로 정밀 구조화하고, 이를 로컬 마크다운 지식베이스(**`LLM Wiki`**)로 축적하는 파이프라인이 표준화되었습니다.
  - 소스코드가 없는 구형 납품 장비나 레거시 윈도우 프로그램(`.exe`)을 **`REA (Reverse Engineer Anything) + Ghidra + Frida + tshark`**로 정적·동적 역공학하여 현대적 **`FastAPI + React`** 스택으로 재구현하는 프로젝트가 급증하고 있습니다.
