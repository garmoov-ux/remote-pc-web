## 3. 프론트엔드-백엔드 연결 필수 실전 코드 3선

### 3.1. 개발 환경 `vite.config.ts` 백엔드 API 및 WebSocket 프록시 설정
프론트엔드(`:5173`)와 백엔드(`:8000`)가 분리되어 있을 때 CORS 에러 없이 `/api/...`와 `/ws/...`를 호출하게 해주는 필수 설정입니다.

```typescript
// frontend/vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [react(), tailwindcss()],
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://127.0.0.1:8000',
        changeOrigin: true,
      },
      '/ws': {
        target: 'http://127.0.0.1:8000',
        ws: true,
      },
    },
  },
});
```

### 3.2. 운영 배포 시 별도 웹서버 없이 FastAPI가 React 빌드(`dist/`)까지 한 번에 서빙하는 코드
도커나 Nginx 없이 윈도우 서버나 포터블 `.exe`에서 파이썬 `FastAPI` 하나만 켜도 React 화면과 API가 동시에 뜨게 해주는 통합 코드입니다.

```python
# backend/app/main.py
from pathlib import Path
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles
from fastapi.responses import FileResponse

app = FastAPI(title="Integrated Web & API Server")

# 1. API 라우터 먼저 등록 (/api/...)
@app.get("/api/health")
async def health_check():
    return {"status": "ok"}

# 2. React 빌드 폴더(frontend/dist)가 존재하면 정적 파일 및 SPA 라우팅 서빙
DIST_DIR = Path(__file__).resolve().parent.parent.parent / "frontend" / "dist"

if DIST_DIR.exists():
    app.mount("/assets", StaticFiles(directory=DIST_DIR / "assets"), name="assets")

    @app.get("/{full_path:path}")
    async def serve_spa(full_path: str):
        file_path = DIST_DIR / full_path
        if file_path.is_file():
            return FileResponse(file_path)
        return FileResponse(DIST_DIR / "index.html")
```

### 3.3. 지수 백오프 자동 재연결 WebSocket 커스텀 훅 (`useRealtimeSocket.ts`)
실시간 대시보드 화면에서 네트워크 순단 발생 시 지수 백오프(Exponential Backoff)로 자동 재연결하는 필수 훅입니다.

```typescript
// frontend/src/hooks/useRealtimeSocket.ts
import { useEffect, useRef, useState } from 'react';

export function useRealtimeSocket<T>(url: string, onMessage?: (data: T) => void) {
  const [isConnected, setIsConnected] = useState(false);
  const wsRef = useRef<WebSocket | null>(null);
  const retryCountRef = useRef(0);

  useEffect(() => {
    let isMounted = true;
    let reconnectTimer: ReturnType<typeof setTimeout>;

    const connect = () => {
      const protocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:';
      const wsUrl = url.startsWith('ws') ? url : `${protocol}//${window.location.host}${url}`;
      const ws = new WebSocket(wsUrl);
      wsRef.current = ws;

      ws.onopen = () => {
        if (!isMounted) return;
        setIsConnected(true);
        retryCountRef.current = 0;
      };

      ws.onmessage = (event) => {
        if (!isMounted) return;
        try {
          const parsed = JSON.parse(event.data) as T;
          onMessage?.(parsed);
        } catch (err) {
          console.error('WebSocket JSON 파싱 오류:', err);
        }
      };

      ws.onclose = () => {
        if (!isMounted) return;
        setIsConnected(false);
        const delay = Math.min(1000 * Math.pow(2, retryCountRef.current), 10000);
        retryCountRef.current += 1;
        reconnectTimer = setTimeout(connect, delay);
      };
    };

    connect();

    return () => {
      isMounted = false;
      clearTimeout(reconnectTimer);
      wsRef.current?.close();
    };
  }, [url]);

  return { isConnected };
}
```

## 4. 화면 구성 분야별 검증된 UI 부품(라이브러리) 사전 (실사용 순위순)

### 4.1. 디자인 및 레이아웃 부품
1. **Tailwind CSS v4 (`@tailwindcss/vite`)**: 별도 설정 파일 없이 CSS 첫 줄에 `@import "tailwindcss";`만 선언하면 동작하는 유틸리티 CSS 표준입니다.
2. **shadcn/ui (React 1순위) / DaisyUI (HTML·Jinja2·Vue 공통)**: 모달(Dialog), 날짜 범위 선택기(Date Range Picker), 드롭다운, 탭, 토스트 알림을 복사해서 즉시 사용합니다.
3. **Lucide Icons (`lucide-react` / `lucide`)**: 1,500여 개의 깔끔한 표준 SVG 아이콘 세트입니다.

### 4.2. 대시보드, 그리드, 차트, 지도, 캔버스 부품
1. **대용량 데이터 그리드 (`TanStack Table` + `@tanstack/react-virtual` 또는 `AG Grid`)**: 5만~10만 건의 로그나 목록을 렌더링해도 버벅임이 없는 가상 스크롤(Virtual Scroll), 다중 필터, 정렬, 엑셀 내보내기를 지원합니다.
2. **인터랙티브 통계 차트 (`Recharts` 또는 `Apache ECharts`)**: 시간대별 추이 곡선, 비율 도넛 차트, 기간별 비교 막대그래프를 반응형으로 렌더링합니다.
