# 실무 에이전트 스킬 최근 3개월 급상승 100선 레퍼런스 가이드

- **산정 기간**: 2026년 8월 ~ 2026년 10월 (최근 3개월)
- **산정 지표**: skills.sh 설치 급증률, GitHub 스타 상승 모멘텀, 최신 에이전트 워크플로우 채택률
- **작성 일자**: 2026년 10월 25일
- **적용 대상**: Antigravity, Claude Code, Cursor, Windsurf 등 에이전트 기반 개발 워크스페이스

---

## 1. 최근 3개월 스킬 생태계 핵심 트렌드 3가지 요약

### 1.1 바이너리 및 네트워크 패킷 역공학 스킬의 폭발적 성장
- 소스코드나 통신 규격서가 유실된 레거시 장비 프로그램(`.exe`, `.dll`), 모바일 앱(`.apk`), Electron 번들, 네트워크 패킷 캡처(`.pcap`)를 에이전트가 직접 디컴파일하고 런타임 후킹하여 재구축하는 `reverse-engineer-anything(REA)` 계열 스킬이 최근 3개월간 가장 가파른 성장세를 기록했습니다.
- 단순 코드 생성 단계를 넘어, 기존 상용/레거시 바이너리와 신규 구현체 간의 동작 동등성을 증거 기반으로 검증하는 워크플로우가 실무 표준으로 자리 잡았습니다.

### 1.2 시니어 엔지니어링 규율 강제(Discipline Enforcement) 스킬의 대세화
- 에이전트가 성급하게 코드를 추측하여 작성하는 것을 막고, 설계 인터뷰(`grill-me`), 아키텍처 의사결정 기록(`write-a-prd`), TDD 선행, 근본 원인 디버깅 및 구현 후 교차 검증(`impl-validator`)을 강제하는 `superpowers`와 `mattpocock/skills`가 폭발적으로 채택되었습니다.
- 프롬프트 요령에 의존하던 방식에서 벗어나 에이전트에게 시니어 아키텍트의 작업 절차 자체를 부여하는 메타 스킬이 실무 생산성을 주도하고 있습니다.

### 1.3 에이전트 장기 기억 위키(`llm-wiki`), 온디바이스 AI(`ai-wasm`), 차세대 모던 스택 급부상
- 과거 대화 내역과 사내 문서를 마크다운 지식 그래프로 영구 축적하는 `llm-wiki` 및 `memory-bridge` 스킬군이 에이전트의 세션 간 기억 휘발 문제를 해결하며 필수 도구로 부상했습니다.
- 동시에 서버 비용 없이 브라우저 내부에서 동작하는 `ai-wasm`(ONNX/WebGPU), 크롬 확장 표준으로 등극한 `WXT`, `Tailwind CSS v4`, 초고속 데이터/문서 처리 도구인 `uv`, `Polars`, `DuckDB`, `Docling`, `MarkItDown` 전용 스킬이 기존 레거시 스택을 빠르게 대체하고 있습니다.
