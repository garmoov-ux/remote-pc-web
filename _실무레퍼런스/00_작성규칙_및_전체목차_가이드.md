이 문서는 언제 다시 열람하더라도 한눈에 핵심을 파악할 수 있도록 **문서 작성 표준 규칙**을 정의하고, 향후 '최근 3개월', '최근 1개월', '특정 분기' 100순위 자료가 추가될 때 일관성을 유지하기 위한 마스터 지침서입니다.

## 1. 레퍼런스 문서 작성 6대 절대 규칙 (향후 작업 시 필수 준수)

앞으로 이 폴더의 문서를 수정하거나 새로운 기간별(예: 최근 1개월, 특정 연도/분기) 100순위 문서를 추가할 때 AI 에이전트와 작성자는 반드시 아래 6가지 규칙을 준수합니다.

### 규칙 1. 이모지(Emoji) 전면 사용 금지
- 문서의 제목, 본문, 리스트, 코드 주석, 다이어그램 어디에도 그림 문자(이모지)를 사용하지 않습니다.
- 강조가 필요할 때는 굵은 글씨(`**텍스트**`), 대괄호 라벨(`[공용 글로벌]`, `[필수]`, `[주의]`), 인용 블록(`>`)만 사용하여 가독성과 전문성을 유지합니다.

### 규칙 2. 복잡한 표(Table) 대신 '헤더 + 핵심 3줄 불릿' 규격 적용
- 화면 폭에 따라 줄바꿈이 깨지고 읽기 피로도를 높이는 다열 마크다운 표(Table) 사용을 지양합니다.
- 모든 1~100순위 항목은 아래의 **표준 3줄 불릿 레이아웃**으로 통일하여 작성합니다.

```markdown
### 001. 항목 이름 (`패키지명 또는 저장소`) [분류 / 설치위치]
- **역할**: 해당 스킬, MCP, 기술스택, 오픈소스가 무엇이며 언제 쓰는지 1~2문장으로 명확히 정의
- **조합**: 함께 사용하는 `[기술스택]` + `[짝꿍 스킬]` + `[짝꿍 MCP]` 조합 명시
- **명령**: 즉시 설치·실행하는 명령어 또는 핵심 설정 1줄
```

### 규칙 3. 실사용 빈도 및 채택률 최우선 배치 (잘 안 쓰는 레거시는 최하단 배치)
- 모든 설명, 아키텍처 옵션, 1~100위 목록에서는 **현재 현업에서 가장 많이 사용하는 주류(Mainstream) 기술을 최상단(1순위)**에 배치합니다.
- 구형 레거시 호환용 기술이나 특수 목적(니치) 기술은 반드시 목록의 **가장 뒤쪽(하위 순위)**으로 배치하여 선택 시 혼선을 방지합니다.

### 규칙 4. 특정 지엽적 도메인 용어 배제 및 범용 실무 예제 사용
- 특정 단일 산업군에 종속된 고유명사나 지엽적인 용어를 배제하고, **웹 서비스, SaaS, 데스크톱 앱(`.exe`), 모바일 앱(`.apk`), 크롬 확장프로그램, 실시간 대시보드, IoT/장비 통신, 오피스 자동화** 등 범용 소프트웨어 엔지니어링 표준 용어와 예제를 사용합니다.

### 규칙 5. 통합 100순위 vs 기간별(최근 3개월 / 최근 1개월) 100순위 산정 기준
- **통합 1~100순위 (`01_*_통합_100선.md`)**:
  - 출시 시점과 무관하게 **현재 실무 사용 빈도, 필수도, 안정성, 현업 채택률**을 종합하여 가장 가치 있는 순서대로 1위부터 100위까지 수록합니다.
- **최근 3개월 1~100순위 (`02_*_최근3개월_100선.md`)**:
  - 기준일로부터 **직전 3개월(예: 2026.08 ~ 2026.10) 동안의 스타 증가 속도, 다운로드 급증세, 신기능 출시, 생태계 세대교체 모멘텀**이 가장 높은 1위부터 100위까지 수록합니다.
- **향후 기간별 추가 규칙**:
  - 사용자가 향후 "최근 1개월 100선", "2027년 1분기 100선" 등을 요청하면 기존 파일을 덮어쓰지 않고 해당 카테고리 폴더 안에 `03_*_최근1개월_100선.md` 또는 `04_*_2027Q1_100선.md` 형태로 나란히 추가합니다.
  - 모든 순위 문서 최상단에는 `산정 기간`, `산정 지표`, `작성 일자` 3줄을 반드시 명시합니다.

### 규칙 6. 기술 스택 + 스킬(Skills) + MCP의 상호 연결 및 범용 경로 명시
- 스킬 문서에서는 어떤 **기술 스택**과 **MCP**에 연결되는지 적고, MCP 문서에서는 어떤 **스킬** 및 **기술 스택**과 결합하는지 적으며, 기술 스택 문서에서는 필요한 **스킬**과 **MCP**를 반드시 함께 표기합니다.
- 특정 PC의 사용자 계정명에 종속되지 않도록 홈 디렉터리 경로는 항상 `%USERPROFILE%` (또는 `~`)를 기본으로 표기합니다.

## 4. 프로젝트 유형별 [기술 스택 + 스킬 + MCP] 핵심 요약 (실사용 빈도순)

### 유형 A. 크롬 확장프로그램 (캡처, PDF 생성, 화면 녹화, 온디바이스 AI) [1순위 주력]
- **기술 스택**: `pnpm + WXT + React 19 + TypeScript 5 + Tailwind v4 + Offscreen Document + IndexedDB (Dexie.js) + pdf-lib + ONNX/Tesseract WASM`
- **필수 스킬**: `wxt`, `chrome-mv3`, `chrome-extensions`, `indexeddb-storage`, `web-audio-video`, `pdf-lib`, `ai-wasm`, `i18n-localization`, `tailwind-design-system`
- **필수 MCP**: `Context7` (공식 문서 실시간 조회) + `Playwright` (UI 렌더링 및 콘솔 에러 검증) + `Sequential Thinking`

### 유형 B. 모던 웹서비스, SaaS 및 실시간 모니터링 대시보드 [2순위 주력]
- **기술 스택**: `Python 3.12 (uv) + FastAPI (REST/WebSocket) + React 19 (Vite 6) + Tailwind v4 + shadcn/ui + PostgreSQL 16 + Redis 7` (빠른 사내 어드민은 `FastAPI + Jinja2 + HTMX 2.0`)
- **필수 스킬**: `uv-package-manager`, `fastapi-templates`, `vercel-react-best-practices`, `tailwind-design-system`, `postgresql`, `sqlalchemy-orm`, `docker-compose-orchestration`
- **필수 MCP**: `Context7`, `Playwright`, `Sequential Thinking` (글로벌) + `PostgreSQL MCP`, `Redis MCP`, `Docker MCP` (프로젝트 로컬)

### 유형 C. 올인원 Windows 데스크톱 설치형 및 포터블 프로그램 (`.exe`) [3순위 주력]
- **기술 스택**: `Electron (또는 Tauri 2.0) + React + Tailwind + 내장 Python FastAPI (.exe Sidecar) + SQLite (WAL 모드)` (초경량 무설치 포터블 유틸리티는 `Python + Pywebview / PySide6 + PyInstaller`)
- **필수 스킬**: `electron-architecture`, `electron-python-sidecar`, `python-packaging`, `sqlite-embedded-db`, `frontend-design`
- **필수 MCP**: `Context7` + `SQLite MCP` + `Playwright`

- **기술 스택**: `Excel VBA (시트 버튼 UI) + Python CLI (PyInstaller .exe) + openpyxl / polars / python-docx / python-pptx / pypdf / MarkItDown / Docling`
- **필수 스킬**: `xlsx`, `docx`, `pptx`, `pdf` (글로벌 4대 오피스 스킬), `vba-excel-automation`, `openpyxl-excel-reporting`
