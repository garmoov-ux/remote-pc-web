# 테스트 규칙 (Testing Rules)

## 1. 테스트 실행 도구
- Python 백엔드 단위/통합 테스트는 `uv run pytest`로 실행한다.
- 웹 프론트엔드 및 원격 PC방 포털 E2E 검증은 `Playwright` (`npx playwright test`) 또는 `Playwright MCP`로 수행한다.

## 2. 핵심 도메인 테스트 작성 원칙
- 실제 운영 DB나 외부 분석 스크립트(Google Ads `gtag`, 네이버 프리미엄 로그분석 `wcs`)를 테스트 환경에서 직접 호출하지 않고 안전한 Mock 픽스처를 사용한다.
- 원격 PC방 포털 핵심 기능은 성공 케이스와 함께 아래 경계 케이스를 반드시 테스트한다:
  - **네비게이션 및 스크롤 스파이**: 상단 메뉴(`#how`, `#games`, `#why`, `#notice`, `#faq`) 클릭 시 해당 섹션으로 정확히 이동하고 `is-active` 상태가 갱신되는지 검증, 모바일 뷰포트(`< 900px`)에서 햄버거 메뉴 오픈/닫기 동작 검증
  - **서비스 게임 카탈로그 (`#games`)**: 50여 종 게임 카드 렌더링, 장르별 필터링, 한글 초성 검색(예: `ㄹㅅㅌㅇㅋ` -> `로스트아크`, `ㅁㅇㅍ` -> `메이플스토리`), 이용 제한 게임(던파·롤·발로란트 불가) 안내 배지 노출 검증
  - **주의사항 및 원격지원 (`#notice`)**: 접속기 종료 방법 2단계, 20분 의무 사용 안내, AnyDesk 원격지원 링크(`rel="noopener noreferrer"`), 24시간 고객센터(`010-3470-8716`, 카카오톡 상담) 렌더링 검증
  - **자주 묻는 질문 (`#faq`)**: 아코디언 클릭 시 답변 펼침/접힘 상태 전환 및 접근성 검증
  - **접속기 다운로드 (`#download` & CTA)**: 상단·히어로·하단·푸터의 모든 `접속기 설치` 버튼이 유효한 설치 URL 및 다운로드 이벤트 핸들러와 연결되어 있는지 검증
  - **모션 감소 접근성 (`prefers-reduced-motion`)**: 모션 감소 설정 시 Canvas 파티클 무한 루프가 중단되고 단일 정적 프레임으로 안전하게 폴백되는지 검증
